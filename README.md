# SearchVerse
Tres misiones interactivas para aprender métodos de búsqueda en Python 3.

Ejecutar `python main.py` desde esta carpeta. No requiere dependencias externas.
Cada módulo también se puede ejecutar por separado: `python secuencial.py`, `python binaria.py` o `python hash.py`.
Los datos son ficticios; los boletos usados se conservan solo durante una sesión del festival.
