# Métodos de ordenamiento en Python

Cuatro programas independientes: ShellSort, QuickSort, HeapSort y RadixSort.

## Ejecución

Ejecuta cada archivo desde la terminal con `python shellsort.py`, `python quicksort.py`, `python heapsort.py` o `python radixsort.py`.

Cada programa tiene un menú: opción 1 para ingresar números enteros y ordenarlos; opción 2 para salir. Admite números negativos y repetidos.

## Documentación

El archivo Word incluido explica los cuatro ejercicios. Sustituye el espacio del enlace por la URL real del repositorio después de subir los archivos a GitHub.
